0.1 แอปนี้ทำอะไรได้

SEMed Tools เป็นโปรแกรมบนคอมพิวเตอร์ Windows ที่รวมเครื่องมือของ SEMed ไว้ที่เดียว ปัจจุบันมี 2 หน้า:

แท็บใช้ทำอะไรดูบท
ตรวจไฟล์ผลตรวจปอดตรวจว่าไฟล์ผลตรวจปอด (Spirometry) ชนิด .xls .xlsx .csv กรอกครบและถูกรูปแบบหรือไม่ แล้วส่งออกรายการที่ผิดเป็น Excel/CSVบทที่ 2
โปรแกรมอื่นดาวน์โหลดโปรแกรมของ SEMed (เช่น SEMed Scanner, โปรแกรมอ่านบัตรประชาชน) หรือเปิดเว็บเครื่องมือ (สร้าง QR Code)บทที่ 3
หมายเหตุการตรวจไฟล์ทำในเครื่องของคุณเท่านั้น แอปไม่แก้ไขไฟล์ต้นฉบับ และไม่ส่งข้อมูลในไฟล์ออกอินเทอร์เน็ต (ตามที่ระบุไว้บนหน้าจอ)

0.3 สิทธิ์การใช้งาน

แอปนี้ ไม่มีระบบล็อกอินและไม่แบ่งสิทธิ์ผู้ใช้ ทุกคนที่ติดตั้งแอปจะเห็นเมนูเหมือนกันทั้งหมด จึงไม่มีรหัสสิทธิ์ในคู่มือนี้ ส่วนที่เป็นงานของผู้ดูแล (ปล่อยเวอร์ชัน เพิ่มเครื่องมือ) อยู่ใน บทที่ 5 และทำผ่านโค้ดของโปรเจค ไม่ใช่ผ่านหน้าจอแอป

1ติดตั้งและโครงสร้างหน้าจอ

1.1 ติดตั้งแอป

  1. รับไฟล์ตัวติดตั้งชื่อ semed-tools-setup-เลขเวอร์ชัน.exe จากผู้ดูแล
  2. ดับเบิลคลิกไฟล์ เลือกโฟลเดอร์ติดตั้งได้ (ตัวติดตั้งยอมให้เปลี่ยนโฟลเดอร์)
  3. เมื่อติดตั้งเสร็จ เปิดแอปจากทางลัดชื่อ SEMed Tools
ข้อควรระวังตัวติดตั้งยังไม่ได้เซ็นชื่อดิจิทัล (code signing) Windows SmartScreen อาจแสดงคำเตือนตอนติดตั้งครั้งแรก — ให้ติดตั้งต่อได้หากไฟล์มาจากผู้ดูแลของ SEMed

ติดตั้งครั้งเดียวพอ หลังจากนั้นแอปจะแจ้งเมื่อมีเวอร์ชันใหม่เอง (ดู บทที่ 4)

1.2 โครงสร้างหน้าจอ

ส่วนข้อความบนหน้าจอหน้าที่

1.3 รูปแบบการทำงานที่พบบ่อย

  • ลากแล้ววาง หรือคลิกเลือก — ใช้กับกล่องเลือกไฟล์ในหน้าตรวจไฟล์
  • ผลการตรวจเป็นการ์ดพับได้ — คลิกที่แถวของไฟล์เพื่อเปิด/ปิดรายละเอียด
  • รายการยาวถูกย่อไว้ — ตารางแสดงก่อน 50 รายการ กด แสดงทั้งหมด (จำนวน รายการ) เพื่อดูที่เหลือ
  • แอปไม่มีการลบข้อมูลของผู้ใช้ — จึงไม่มีหน้าต่างยืนยันการลบ

2ตรวจไฟล์ผลตรวจปอด

2.1 วัตถุประสงค์และเมนูที่ใช้

ตรวจไฟล์ผลตรวจปอด (Spirometry) ก่อนนำไปใช้ต่อ ว่ามีคอลัมน์ครบ ค่าถูกรูปแบบ และแต่ละ CN มีผล BestTrial ที่ถูกต้องเพียง 1 แถว เมนู: แท็บ ตรวจไฟล์ผลตรวจปอด (เปิดอยู่เป็นหน้าแรกเมื่อเปิดแอป) ไม่ต้องมีสิทธิ์พิเศษ

2.2 เลือกไฟล์ที่จะตรวจ

  1. เปิดแท็บ ตรวจไฟล์ผลตรวจปอด
  2. ลากไฟล์มาวางในกรอบ ลากไฟล์ผลตรวจมาวางที่นี่ หรือ เลือกจากเครื่อง หรือคลิกกรอบ (หรือกด Enter / Space เมื่อกรอบถูกเลือกอยู่) แล้วเลือกไฟล์จากเครื่อง
  3. ตรวจรายการไฟล์ที่ปรากฏ (ชื่อไฟล์และขนาด)
  4. กด ตรวจสอบ ปุ่มจะเปลี่ยนเป็น กำลังตรวจ... ชั่วครู่
  5. ผลการตรวจจะแสดงด้านล่าง (ดู 2.4)

ชนิดไฟล์ที่รองรับ.xls .xlsx .csv
จำนวนไฟล์ต่อครั้งไม่เกิน 20 ไฟล์
ขนาดต่อไฟล์ไม่เกิน 10 MB
ข้อควรระวังการเลือกไฟล์ชุดใหม่จะ แทนที่ ชุดเดิมและล้างผลการตรวจเก่าทันที ถ้าต้องการตรวจต่อเนื่องหลายชุด ให้ส่งออกผล (2.6) ก่อนเลือกชุดใหม่
หมายเหตุถ้าเลือกเกิน 20 ไฟล์ แอปจะตัดส่วนที่เกินออกและแจ้งว่า เลือกได้สูงสุด 20 ไฟล์ — ตัดไฟล์ที่เกินออก N ไฟล์ ส่วนไฟล์ที่เกิน 10MB จะแจ้งว่า ไฟล์ที่เกิน 10MB จะถูกรายงานว่าไม่สมบูรณ์: ชื่อไฟล์
เคล็ดลับถ้าลากไฟล์พลาดไปวางนอกกรอบ แอปจะไม่เปิดไฟล์นั้นทับหน้าต่าง ลากใหม่ได้เลย กด ล้างไฟล์ เพื่อเริ่มใหม่

2.3 โครงสร้างไฟล์ที่แอปคาดหวัง

  • แอปอ่านเฉพาะ ชีตแรก ของไฟล์ Excel และถือว่า แถวที่ 1 คือหัวคอลัมน์
  • หัวคอลัมน์ไม่สนตัวพิมพ์เล็ก/ใหญ่ ต้องมี 4 คอลัมน์นี้:
คอลัมน์บังคับกฎของค่า
Code*ห้ามว่าง ส่วนที่อยู่ก่อนจุดแรกต้องเป็นตัวเลขล้วน เรียกว่า CN เช่น 10234.1 → CN 10234
BestTrial*เว้นว่าง หรือเป็น X / BEST (ไม่สนตัวพิมพ์) เท่านั้น
FVC*ห้ามว่าง ต้องเป็นตัวเลข (ติดลบ/ทศนิยมได้)
FEV1*ห้ามว่าง ต้องเป็นตัวเลข (ติดลบ/ทศนิยมได้)

กฎระดับ CN: ในแต่ละ CN ต้องมีแถวที่ทำเครื่องหมาย BestTrial (X หรือ BEST) แค่ 1 แถว ไม่มี หรือมีมากกว่า 1 ถือว่าผิด

หมายเหตุเลขแถวที่แอปรายงานตรงกับเลขแถวใน Excel (แถวหัวคอลัมน์คือแถว 1) แถวที่ว่างทั้งแถวถูกข้าม และไฟล์ CSV รองรับตัวคั่น ; , หรือแท็บ (แอปเดาจากบรรทัดแรก) รวมถึงไฟล์ภาษาไทยแบบเก่า

2.4 อ่านผลการตรวจ

  1. บรรทัดสรุป: ไฟล์ทั้งหมด | สมบูรณ์ | ไม่สมบูรณ์
  2. การ์ดของแต่ละไฟล์ — ไฟล์ ไม่สมบูรณ์ขึ้นก่อน แล้วตามด้วยไฟล์ที่สมบูรณ์ คลิกที่การ์ดเพื่อเปิด/ปิดรายละเอียด
  3. ตัวเลขบนการ์ด: แถว (จำนวนแถวข้อมูล) · CN (จำนวน CN) · ผ่าน · ผิด · คำเตือน
  4. ในการ์ดที่เปิด: ตาราง แถว / CN / สาเหตุ หัวข้อ รายการผิดพลาด N รายการ และ คำเตือน N รายการ ถ้าไม่มีอะไรเลยจะขึ้น ไม่พบปัญหา
หมายเหตุคำเตือน (เช่น พบ CN เดียวกันในไฟล์อื่นด้วย) ไม่ทำให้ไฟล์เป็น "ไม่สมบูรณ์" — ไฟล์จะถูกนับว่า "ไม่สมบูรณ์" ก็ต่อเมื่อมีรายการผิดพลาดหรือปัญหาระดับไฟล์ ควรอ่านคำเตือนเสมอ เพราะอาจเป็น CN ซ้ำจริง

2.6 ส่งออกผลการตรวจ

  1. หลังตรวจเสร็จ กด ส่งออกผลเป็น CSV/Excel
  2. ในหน้าต่างบันทึก (ชื่อเริ่มต้น ผลตรวจสอบไฟล์ผลตรวจปอด.xlsx) เลือกชนิด Excel หรือ CSV แล้วเลือกที่เก็บ
  3. เมื่อสำเร็จจะขึ้น ส่งออกสำเร็จ: ชื่อไฟล์ กด เปิดโฟลเดอร์ เพื่อไปที่ไฟล์

ไฟล์ที่ส่งออกมีคอลัมน์ ไฟล์ / ประเภท / แถว / CN / สาเหตุ โดยประเภทคือ "ไฟล์" (ปัญหาระดับไฟล์) "ผิดพลาด" หรือ "คำเตือน" ใช้ชีตชื่อ "ผลตรวจ" หากกดยกเลิกในหน้าต่างบันทึกจะไม่มีอะไรเกิดขึ้น ถ้าบันทึกไม่ได้ จะขึ้น ส่งออกไม่สำเร็จ: ...

ข้อควรระวังถ้าบันทึกทับไฟล์ชื่อเดิมที่เปิดค้างอยู่ใน Excel อาจบันทึกไม่ได้ ให้ปิดไฟล์นั้นก่อนหรือตั้งชื่อใหม่ (ยังไม่ได้ทดสอบกับกรณีนี้โดยตรง)

3โปรแกรมอื่น (ดาวน์โหลดโปรแกรม / เปิดเว็บ)

3.1 วัตถุประสงค์และเมนูที่ใช้

รวมโปรแกรมและเว็บเครื่องมือของ SEMed ไว้ให้ดาวน์โหลดหรือเปิดจากที่เดียว เมนู: แท็บ โปรแกรมอื่น ต้องเชื่อมต่ออินเทอร์เน็ต (เพื่อดึงรายการจาก GitHub) ไม่ต้องมีสิทธิ์พิเศษ

3.2 รายการในหน้านี้

รายการปัจจุบัน (ตามโค้ด เวอร์ชัน 1.0.6):

3.3 ดาวน์โหลดและเปิดโปรแกรม

  1. เปิดแท็บ โปรแกรมอื่น ระหว่างรอจะเห็น กำลังโหลดรายการ...
  2. ดูข้อมูลใต้ชื่อโปรแกรม: ล่าสุด เวอร์ชัน · ขนาด MB · ตรวจ SHA-256 (ข้อความ "ตรวจ SHA-256" แสดงเมื่อ GitHub มีค่ารับรองไฟล์) และสถานะ ติดตั้งแล้ว vX หรือ ติดตั้งอยู่ vX · มีเวอร์ชันใหม่
  3. กดปุ่มของโปรแกรม ปุ่มจะแสดง กำลังโหลด N%
  4. เมื่อเสร็จ จะขึ้น ดาวน์โหลดสำเร็จ: ชื่อไฟล์ พร้อมปุ่ม แสดงในโฟลเดอร์ และปุ่มโปรแกรมเปลี่ยนเป็น เปิดตัวติดตั้ง (หรือ เปิดโปรแกรม สำหรับโปรแกรมพกพา)
  5. กดปุ่มนั้นเพื่อเปิดไฟล์ Windows อาจถามสิทธิ์ผู้ดูแลเครื่อง

3.4 ความปลอดภัยของไฟล์ที่ดาวน์โหลด

  • แอปโหลดได้เฉพาะไฟล์จาก Release ของที่เก็บ GitHub ที่ SEMed กำหนดไว้เท่านั้น
  • ถ้า GitHub มีค่า SHA-256 รับรอง แอปจะตรวจให้ ถ้าไม่ตรงจะลบไฟล์ทิ้งและแจ้งให้ทราบ
  • แอปเปิดได้เฉพาะไฟล์ที่ตัวเองเพิ่งดาวน์โหลดในรอบการใช้งานนั้น

3.5 ข้อความที่พบบ่อยและวิธีแก้

ข้อความความหมาย / วิธีแก้

เคล็ดลับแอปจำรายการจาก GitHub ไว้ 10 นาที (เพื่อไม่ให้เรียกบ่อยเกินกำหนดของ GitHub) หากเพิ่งมีโปรแกรมเวอร์ชันใหม่แล้วยังไม่เห็น กด โหลดรายการใหม่ เพื่อบังคับโหลดใหม่

4อัปเดตแอป SEMed Tools

4.1 วัตถุประสงค์

แอปตรวจหาเวอร์ชันใหม่เองทุกครั้งที่เปิด (ต้องมีอินเทอร์เน็ต) แอปจะไม่ดาวน์โหลดหรือติดตั้งอะไรโดยไม่ถามคุณ ถ้าออฟไลน์ยังใช้งานได้ตามปกติ

4.2 ขั้นตอนอัปเดต

  1. เมื่อพบเวอร์ชันใหม่ แถบด้านบนแสดง มีเวอร์ชันใหม่ X กด อัปเดตเลย
  2. แถบแสดง กำลังเริ่มดาวน์โหลด... แล้ว กำลังดาวน์โหลดอัปเดต N%
  3. เมื่อเสร็จแสดง ดาวน์โหลดเวอร์ชัน X เรียบร้อยแล้ว กด ติดตั้งและรีสตาร์ท แอปจะปิดแล้วเปิดใหม่เป็นเวอร์ชันใหม่
ข้อควรระวังก่อนกด ติดตั้งและรีสตาร์ท ให้ส่งออกผลการตรวจที่ยังต้องใช้ (2.6) เพราะผลบนหน้าจอจะหายเมื่อแอปปิด

4.3 เลื่อนอัปเดตและตรวจเอง

  • ไว้ทีหลัง — ซ่อนแถบจนกว่าจะเปิดแอปครั้งถัดไป
  • ตรวจสอบอัปเดต (มุมบนของหน้าจอ) — ตรวจเองได้ทุกเมื่อ จะขึ้น เป็นเวอร์ชันล่าสุดแล้ว ถ้าไม่มีของใหม่

5สำหรับผู้ดูแล (ปล่อยเวอร์ชันและเพิ่มเครื่องมือ)

ข้อควรระวังบทนี้สำหรับผู้ดูแลที่มีโค้ดโปรเจคและ Node.js ต้องใช้คำสั่งในโปรเจค ไม่ใช่หน้าจอของแอป ผู้ใช้ทั่วไปข้ามได้ สรุปจาก README ของโปรเจค (ยังไม่ได้ทดลองรันทุกคำสั่งขณะเขียนคู่มือ)

5.1 ปล่อยเวอร์ชันใหม่

  1. ครั้งแรก: สร้าง GitHub token (Fine-grained: Contents Read and write หรือ classic: repo) คัดลอก .env.example เป็น .env ใส่ GH_TOKEN=... (ไฟล์ .env ไม่ขึ้น git)
  2. commit โค้ดให้เรียบร้อย (working tree ต้องสะอาด)
  3. รันคำสั่งเดียว
คำสั่งผล
npm run shippatch (1.0.0 → 1.0.1) — แก้บั๊ก/ปรับข้อความ
npm run ship:minorminor (1.0.1 → 1.1.0) — เพิ่มความสามารถใหม่
npm run ship:majormajor (1.1.0 → 2.0.0) — เปลี่ยนพฤติกรรมครั้งใหญ่

ลำดับ: npm test → เพิ่มเลขเวอร์ชัน + tag → git push --follow-tags → build และอัปโหลด Release → ตรวจ Release บน GitHub ให้เอง ถ้าขึ้น ✓ แปลว่าผู้ใช้อัปเดตได้ ถ้าพังกลางทาง รัน npm run release ซ้ำได้ ตรวจอย่างเดียวด้วย npm run release:check

อันตรายห้ามลบหรือแก้ไฟล์ latest.yml ใน Release ด้วยมือ และ repo ต้องเป็น public (ห้ามใส่ข้อมูลคนไข้ใน repo) มิฉะนั้นเครื่องผู้ใช้จะอัปเดตไม่ได้

Bภาคผนวก — คำถามที่พบบ่อย

B.1 ไฟล์ของฉันขึ้น "ไม่ใช่ไฟล์ .xlsx จริง"

มักเกิดจากเปลี่ยนนามสกุลเอง เปิดไฟล์ใน Excel แล้ว บันทึกเป็น ชนิด .xlsx จริง แล้วตรวจใหม่ (ดู 2.5)

B.2 ไฟล์มีหลายชีต แต่แอปตรวจแค่ชีตแรก

ถูกต้อง แอปอ่านเฉพาะชีตแรก ย้ายข้อมูลที่ต้องตรวจมาไว้ชีตแรก

B.3 ผลหายไปหลังเลือกไฟล์ใหม่

เป็นการทำงานปกติ ผลเก่าจะถูกล้างเมื่อเลือกไฟล์ชุดใหม่ ให้ส่งออกก่อน (2.6)

B.4 กด "ตรวจสอบอัปเดต" แล้วบอกว่าตรวจได้เฉพาะแอปที่ติดตั้งแล้ว

แอปที่เปิดในโหมดทดสอบไม่รองรับอัปเดตอัตโนมัติ (4.4)

B.5 Windows เตือนตอนติดตั้ง/เปิดโปรแกรมที่โหลดมา

ตัวติดตั้งยังไม่ได้เซ็นชื่อดิจิทัล จึงอาจมี SmartScreen เตือน ให้ดำเนินการต่อเมื่อมั่นใจว่าไฟล์มาจาก SEMed (ยังไม่ยืนยันพฤติกรรมของโปรแกรมพกพา IDCard_reader.exe)

B.6 ในหน้าโปรแกรมอื่น มีโปรแกรมที่ปุ่มกดไม่ได้

ดูเหตุผลข้างปุ่ม แล้วดู 3.5

Cภาคผนวก — แนวปฏิบัติที่แนะนำ

  • ตรวจหลายไฟล์พร้อมกัน (สูงสุด 20) เพื่อให้แอปเตือน CN ซ้ำข้ามไฟล์ได้
  • แก้ที่ไฟล์ต้นฉบับแล้วตรวจซ้ำจนขึ้น "สมบูรณ์" ทุกไฟล์ก่อนนำไปใช้ต่อ
  • ส่งออกผลเก็บไว้ก่อนอัปเดตแอปหรือก่อนเลือกไฟล์ชุดใหม่
  • ติดตั้งอัปเดตเมื่อแอปแจ้ง เพื่อให้กฎตรวจตรงกับเวอร์ชันล่าสุด
  • ดาวน์โหลดโปรแกรมจากแท็บ โปรแกรมอื่น เท่านั้น เพื่อให้ได้การตรวจ SHA-256
